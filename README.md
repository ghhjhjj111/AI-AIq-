# AI创作小程序源码，文生图，图生图，可对接任何图像AI模型

源码获取：ym7k.com/19846/

这套 AI 绘画创作小程序源码采用 **FastAdmin+ThinkPHP+Uniapp** 开发，微信小程序端，配套 PC 管理后台，核心定位是**中转调用 AI 绘图模型**，不绑定固定模型，可灵活对接 Stable Diffusion、Midjourney、DALL・E、通义万相、即梦等各类第三方图像大模型接口，实现文生图、图生图、图生图重绘、风格化等 AI 绘画能力，适合搭建 AI 绘画平台、AI 素材生成工具、自媒体 AI 出图变现平台，支持私有化部署、二次开发。

## 一、技术架构

后端：ThinkPHP + FastAdmin，负责接口转发、参数封装、用户鉴权、订单扣费、任务队列；
前端：Uniapp，编译微信小程序，也可打包 H5；
核心逻辑：后端做**模型调度层**，小程序提交绘图参数，后端转发请求到你配置的 AI 绘图接口，接收返回图片后回传给前端；
优势：解耦，随时切换模型服务商，不用改动前端页面。

## 二、核心功能

### 1. 文生图（文字生成图片）

输入正向提示词、反向提示词；支持选择画风、尺寸、生成数量、采样器、步数、CFG 权重；支持预设模板（写实、二次元、古风、3D、卡通、海报等），一键填充提示词，降低用户使用门槛。

### 2. 图生图 / 以图生图

上传参考底图，设置重绘幅度；AI 根据原图构图、色彩、轮廓，结合提示词生成新图；支持图片局部重绘、图片扩图（拓展画布）。

### 3. 模型多源切换（重点亮点）

后台可添加多个 AI 绘图接口渠道，自由切换、负载均衡；支持给不同渠道分配权重，某个模型接口失效自动切换备用通道；新增模型只需要在后台配置接口地址、密钥、传参格式，前端无需改代码。

### 4. 用户端能力

微信一键登录；个人作品画廊，保存、收藏、下载生成图片；历史绘图记录，支持复用上次参数重新生成；提示词收藏、提示词广场，用户可以分享优质提示词；生成任务排队，异步出图，避免超时。

### 5. 计费与变现体系

- 点数 / 算力扣费：注册赠送免费点数，绘图消耗点数；
- 充值套餐：充值点数包、月度会员无限次绘图；
- 会员特权：会员优先排队、高清图、解锁专属模型、去除水印；
- 订单明细、充值记录、消耗明细全部可查。

### 6. 后台管理功能

- 渠道模型管理：新增、编辑、启用禁用 AI 接口，配置密钥、请求参数、回调地址；
- 用户管理：用户列表、余额点数、封禁用户；
- 作品审核：用户生成图片审核，违规图片下架、敏感词拦截；
- 提示词管理：提示词分类、预设模板管理；
- 订单财务：充值订单、消耗流水、统计报表；
- 数据看板：新增用户、绘图次数、充值营收图表；
- 系统配置：水印开关、图片存储（OSS / 本地）、排队并发数量、敏感词库。

## 三、适配对接的模型类型

✅ 本地部署 SD 接口（SD-API、ComfyUI 接口）
✅ 国内各大 AI 绘图开放平台接口（通义万相、文心一格等）
✅ MJ 代理接口、各类第三方绘图中转 API
✅ 其他自研图像生成模型接口

> 
> 只要模型提供 HTTP 接口，约定好入参出参格式，后台即可接入。

## 四、适用场景

✅ 自媒体 AI 绘画出图小程序
✅ 设计工作室内部 AI 绘图工具
✅ 知识博主、AI 工具站变现平台
✅ 给学员、会员提供 AI 绘图权益
✅ 定制行业 AI 生成（电商主图、海报、头像、插画）

## 五、系统优势

1. **模型中立**，不锁死单一 AI 模型，渠道灵活替换，不会因为一家接口涨价 / 封控直接停业务；
2. 异步任务队列，支持并发控制，防止接口被打爆；
3. 自带完整商业化：点数充值、会员、作品画廊、审核风控；
4. Uniapp 小程序，上手快，改 LOGO、提示词模板就能上线；
5. 源码可二开，可扩展：AI 图生视频、AI 扩图、高清修复、头像生成、商品图批量生成。
